# yuvraj-borade.github.io

Personal site. Single-file static site, no build step.

Live at <https://yuvraj-borade.github.io/>.

## Structure

```
index.html       — page markup
stylesheet.css   — styles (light + auto dark mode)
images/          — profile photo + project thumbnails (SVG placeholders)
pdfs/            — CV
```

## Editing

Search `index.html` for any item you want to change. To add a project, copy any `<div class="item">` block and edit. To add an experience, copy a `<div class="xp-row">` block.

Replace the SVG placeholders in `images/` with real project images when ready.

Template after [Jon Barron](https://jonbarron.info).
